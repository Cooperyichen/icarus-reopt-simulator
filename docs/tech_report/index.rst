
Welcome to ICARUS Technical Code Guide (sim_net_hts) Documentation!
===================================================================

    This code has been thoroughly tested on Spyder Python 3.11. Additionally, ensure that YAML file data in in the 'data' folder adheres to the YAML standard. 

.. note::

    .. raw:: html

        <p style="color: red; font-weight: bold;">Pay close attention to spacing in YAML data files.</p>

    
.. important::

    To utilize this project effectively, ensure that the following dependencies are installed:

    - **scipy** (version 1.11.1)
    - **networkx** (version 3.1)
    - **pandas** (version 2.0.3)
    - **yaml** (version 6.0)
    - **cvxpy** (version 1.3.2)
    - **simpy** (version 4.0.2)
    - **cvxopt** (version 1.3.2)
    - **pyyaml** (version 6.0.1)
    - **pillow** (version 9.4.0)
    - **sphinx** (version 7.2.6)
