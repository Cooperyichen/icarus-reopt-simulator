Plots package
=============

The Plots package contains a variety of python files designed to generate visualizations for simulation results. Each module focuses on different aspects of the simulations, offering tools to create detailed and informative plots.

==================
Modules Overview
==================

- **simulation\_charts**: This module includes functions for creating general simulation charts.
- **simulation\_charts\_per\_priority**: Focuses on generating charts based on priority levels within simulations.
- **plots\_first\_paper**: Contains plotting functions specifically tailored for the first research paper.
- **plots\_first\_paper\_bis**: An extension of the first paper's plotting functions with additional or alternative visualizations.
- **plots\_second\_paper**: Provides plotting functions for the second research paper.
